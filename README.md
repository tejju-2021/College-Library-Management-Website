# 📚 College Library Management Website

A simple multi-page Library Management Website developed using HTML and CSS. The project demonstrates the use of frames, navigation menus, forms, hyperlinks, tables, and basic CSS styling.

---

## 🚀 Features

- 🏠 Homepage with frame-based navigation
- 🔐 Login Form
- 📝 Registration Form with Validation
- 📖 Branch-wise Book Catalogue
- 🛒 Shopping Cart Page
- 🎨 CSS Styling and Background Effects
- 🔗 Hyperlinks and Navigation Menus
- 📚 Department-wise Book Listings

## 📖 Modules

### 🏠 Home Page
Provides the main interface of the website using HTML Frames.

### 🔐 Login Module
Allows users to enter login credentials.

### 📝 Registration Module
Includes:
- Name Validation
- Email Validation
- Password Validation
- Phone Number Validation

### 📚 Catalogue Module
Displays available books with:
- Book Image
- Author Name
- Publication Details
- Price
- Add to Cart Option

### 🛒 Cart Module
Displays:
- Selected Books
- Quantity
- Price
- Total Amount
